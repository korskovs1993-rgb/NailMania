# Проверка MVP · 11.10.2026

## Выполнено

- Python 3.10.11, изолированное окружение, версии зафиксированы в requirements.txt.
- Миграции применены; `makemigrations --check --dry-run`: изменений нет.
- `manage.py check`: замечаний нет.
- `manage.py test booking` на SQLite: **36 тестов, 35 успешно, 1 пропущен** (конкурентность требует PostgreSQL).
- Повторный полный прогон на настоящей **PostgreSQL 17.11: 36 тестов успешно, без пропусков**. Использован изолированный переносимый сервер EDB на 127.0.0.1:55432, без установки службы Windows и без изменения `.env` приложения.
- Два одновременных запроса из разных соединений PostgreSQL на один интервал: ровно одна запись создана, второму возвращён конфликт. Миграции и восстановление зашифрованной копии также прошли на PostgreSQL.
- Проверены пересечения, соседние визиты, шаг 15 минут, суммирование услуг, личные дела, дневные исключения, горизонт записи и неактивные услуги.
- Проверены одобрение/отклонение, отмена/перенос, повторный запрос, конфликт при одобрении переноса и сохранение старого визита.
- Проверены закрытые страницы, запрет анонимного подтверждения, CSRF, ограничение попыток входа, отсутствие телефона/имени/заметок на публичном статусе.
- Проверена неизменность существующего имени/заметок при новой заявке на тот же телефон и сохранение истории при редактировании услуги.
- Зашифрованная копия восстановлена в пустую тестовую базу; связи, история и проверка пароля пользователя сохранились. Восстановление поверх существующей базы отклоняется.
- Повторные попытки Telegram проверены с имитацией сетевой ошибки; запись в очередь не зависит от доступности Telegram.

## Браузер

Локальный сервер Waitress запускался на Windows. Проверены вход мастера, календарь, выбор нескольких услуг, свободные интервалы, отправка вымышленной заявки, появление в кабинете, подтверждение и обновление клиентского статуса.

Проверены ширины 1366 и 393 CSS-пикселя, все шесть палитр и сохранение темы после перезагрузки. На ширине 393 горизонтальное переполнение не обнаружено. Сохранены изображения интерфейса в outputs рядом с проектом.

На браузерной проверке обнаружены и исправлены формат даты для HTML date input и совместимость политики referrer с отправкой форм. Секретные пути не передаются в Referer: применяется strict-origin. CSRF не отключался.

Запускатор `start.py` / `Start NailBook.cmd` добавлен; синтаксис Python проверен. Полный сценарий первого запуска на другом компьютере не проверялся.

## Не проверено вживую

- Docker Compose, HTTPS, внешний домен, рабочее развёртывание и синхронизация физически разных устройств.
- Физический iPhone 15/Safari, установка PWA, поведение service worker при реальном отключении сети.
- Реальная доставка Telegram: токен и chat_id не предоставлены.
- Планировщик резервного копирования, второй носитель и аварийное восстановление рабочей базы с реальными данными (логическое восстановление тестовой PostgreSQL проверено).
- Юридическое соответствие конкретному оператору: документы пока шаблоны, уведомления РКН не подавались.

Рабочее ядро проверено на локальной SQLite и PostgreSQL 17.11. Это не подтверждение настройки публичной инфраструктуры или юридической готовности конкретного оператора к приёму реальных персональных данных.
